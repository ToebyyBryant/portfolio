Sample Code — PHP REST Endpoint

<?php
// api.php — simple RESTful endpoint example
header('Content-Type: application/json');
header('Access-Control-Allow-Origin: *');

$conn = new mysqli('localhost', 'user', 'pass', 'db');
$method = $_SERVER['REQUEST_METHOD'];

if ($method === 'GET') {
    $result = $conn->query("SELECT * FROM items ORDER BY id DESC");
    $rows = [];
    while ($row = $result->fetch_assoc()) {
        $rows[] = $row;
    }
    echo json_encode(['status' => 'success', 'data' => $rows]);

} elseif ($method === 'POST') {
    $data = json_decode(file_get_contents('php://input'), true);
    $name = $conn->real_escape_string($data['name']);
    $conn->query("INSERT INTO items (name) VALUES ('$name')");
    echo json_encode(['status' => 'created', 'id' => $conn->insert_id]);
}
$conn->close();
?>

Sample Code — CRUD Update Endpoint

<?php
// PUT /api/items/:id — update a record
header('Content-Type: application/json');
$conn = new mysqli('localhost', 'user', 'pass', 'db');

$id   = intval($_GET['id']);
$data = json_decode(file_get_contents('php://input'), true);
$name = $conn->real_escape_string($data['name']);

$conn->query("UPDATE items SET name='$name' WHERE id=$id");

    http_response_code(404);
    echo json_encode(['status' => 'not found']);
}

?>

Project Description

A Windows Communication Foundation (WCF) web service implementing a calculator with four arithmetic operations: Addition, Subtraction, Multiplication, and Division. The service is hosted via BasicHttpBinding at localhost:55307/Service1.svc and exposes both synchronous and asynchronous operation contracts (Add(), AddAsync(), etc.) for each operation.

The project includes two clients: the built-in WCF Test Client for testing the SOAP service directly, and a C# Console App that consumes the service and prompts the user to choose an operation and enter two numbers. All four operations were tested and verified.

Key Features

  • WCF service with IService1 contract exposing Add, Subtract, Multiply, Divide operations
  • Both synchronous and async operation contracts generated automatically
  • Tested via WCF Test Client — inputs two System.Double values, returns System.Double result
  • Service description accessible in browser at localhost:55307/Service1.svc
  • Console App client prompts user to choose operation (1–4) and enter two numbers
  • All four arithmetic functions tested and confirmed working

Sample Code — WCF Service Contract

// IService1.cs — Service Contract
[ServiceContract]
public interface IService1
{
    [OperationContract]
    double Add(double a, double b);

    [OperationContract]
    double Subtract(double a, double b);

    [OperationContract]
    double Multiply(double a, double b);

    [OperationContract]
    double Divide(double a, double b);
}

// Service1.svc.cs — Implementation
public class Service1 : IService1
{
    public double Add(double a, double b)      => a + b;
    public double Subtract(double a, double b) => a - b;
    public double Multiply(double a, double b) => a * b;
    public double Divide(double a, double b)   => a / b;
}

Sample Code — Console App Client

// Program.cs — Console App consuming the WCF service
static void Main(string[] args)
{
    ServiceReference1.Service1Client client = new ServiceReference1.Service1Client();

    Console.WriteLine("Choose equation type:");
    Console.WriteLine("1. Addition\n2. Subtraction\n3. Multiplication\n4. Division");
    Console.Write("Enter choice (1-4): ");
    int choice = int.Parse(Console.ReadLine());

    Console.Write("Enter first number: ");
    double a = double.Parse(Console.ReadLine());
    Console.Write("Enter second number: ");
    double b = double.Parse(Console.ReadLine());

    double result = choice switch
    {
        1 => client.Add(a, b),
        2 => client.Subtract(a, b),
        3 => client.Multiply(a, b),
        4 => client.Divide(a, b),
        _ => throw new ArgumentException("Invalid choice")
    };

    Console.WriteLine($"Result: {result}");
    client.Close();
    Console.WriteLine("Press any key to exit...");
    Console.ReadKey();
}

Static — Scrum 4 Team Project: Real-Time Voting App

Project Description

A real-time voting web application built with Node.js and Socket.IO. Multiple users can simultaneously vote on a preferred free-time activity, with live vote results pushed to all connected clients instantly via WebSockets — no page refresh required.

Key Features

  • Real-time vote updates via Socket.IO broadcast to all connected clients
  • Multi-tab simultaneous voting — all tabs update live
  • Duplicate-vote prevention — submit button disabled after voting
  • Admin reset functionality — clears all vote counters across all clients instantly
  • Event-driven architecture: vote → server increments → io.emit('update') → DOM re-renders
  • Voting activities: Video Games, Reading, Crafty Hobbies, Physical Activity, Board Games

Architecture

3-Tier Real-Time Event-Driven Flow
  • Client (app.js / index.html) ↔ Socket.IO ws:// layer ↔ Server (server/index.js)
  • On connect: Server emits current vote totals to the new socket
  • On vote event: Server increments the correct counter; io.emit broadcasts to all clients
  • On reset event: Server zeroes all counters; io.emit clears all clients
  • Client update handler: Re-renders emoji counters live — no page reload
