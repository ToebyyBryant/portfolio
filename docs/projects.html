Project Description

A full-stack web application for tracking personal income and expenses. Built with Node.js/Express, SQLite, and React — demonstrating MVC architecture, relational DB design, RESTful API patterns, and modern UI skills. No external database installation required; SQLite is bundled and the database file is created automatically on first run.

Architecture

The application is split into two packages inside a monorepo: a Node.js / Express REST API backend and a React (Vite) SPA frontend, plus an HTML presentation slide deck for demo purposes.

Project Structure
  • server/src/config/ — Database config, logger, seeders
  • server/src/middleware/ — JWT auth, error handler
  • server/src/models/ — Sequelize models (User, Category, BudgetEntry)
  • server/src/routes/ — Express route handlers
  • server/src/services/ — Business logic layer
  • server/src/utils/ — JWT helpers, AppError class
  • server/tests/ — Integration tests
  • client/src/api/ — Axios API client modules
  • client/src/components/ — Reusable UI components
  • client/src/pages/ — Page-level components
  • client/src/utils/ — Chart data utilities
  • client/tests/ — Frontend tests
  • presentation/ — HTML slide deck for demo

Request Flow
  • Browser → React SPA (Vite, port 5173) → Express API (port 3001, HTTP + JWT header)
  • JWT Auth Middleware verifies token → attaches req.userId or returns 401
  • Service Layer executes Sequelize query against SQLite
  • JSON response → React re-renders charts and data

Key Features

  • User Authentication — JWT-based registration, login, and protected routes
  • Budget Entries — Full CRUD for income and expense transactions
  • Categories — Default + custom user-defined categories
  • Dashboard — Monthly summary with total income, expenses, and net balance
  • Charts — Pie (expenses by category), Bar (monthly income vs expenses), Line (cumulative balance)
  • Filtering — Filter entries by date range, category, and type
  • Responsive UI — Works on all screen sizes from 320px to 2560px
  • Zero-config DB — SQLite bundled; database file auto-created on first start

Data Models

Three core Sequelize models backed by SQLite:

// User — stores credentials
{ id, email (unique), password_hash, created_at, updated_at }

// Category — default (user_id = NULL) or user-owned
{ id, name, user_id (FK), is_default, created_at }
// Unique constraint: (name, user_id)

// BudgetEntry — core transaction record
{ id, user_id (FK), category_id (FK), amount (DECIMAL 12,2),
  type (ENUM: income|expense), entry_date, description, created_at, updated_at }

Sample Code — JWT Auth Middleware

// server/src/middleware/auth.js
const jwt = require('jsonwebtoken');

module.exports = (req, res, next) => {
  const authHeader = req.headers['authorization'];
  const token = authHeader && authHeader.split(' ')[1]; // Bearer <token>

  if (!token) {
    return res.status(401).json({
      error: { code: 'MISSING_TOKEN', message: 'Authentication required.' }
    });
  }

  try {
    const payload = jwt.verify(token, process.env.JWT_SECRET);
    req.userId = payload.userId;
    next();
  } catch (err) {
    return res.status(401).json({
      error: { code: 'INVALID_TOKEN', message: 'Token is invalid or expired.' }
    });
  }
};

Sample Code — Budget Entry Filter Query

// server/src/services/budgetService.js (getEntries)
const { Op } = require('sequelize');

async function getEntries(userId, { startDate, endDate, categoryId, type }) {
  const where = { user_id: userId };

  if (startDate) where.entry_date = { [Op.gte]: startDate };
  if (endDate)   where.entry_date = { ...where.entry_date, [Op.lte]: endDate };
  if (categoryId) where.category_id = categoryId;
  if (type)       where.type = type;

  return BudgetEntry.findAll({
    where,
    order: [['entry_date', 'DESC']],
    include: [{ model: Category, attributes: ['name'] }]
  });
}

Getting Started

  • Prerequisites: Node.js v18+, npm v9+
  • No database installation required — SQLite is bundled
  • Clone repo → cd server && npm install → cd ../client && npm install
  • Create server/.env with DATABASE_PATH, JWT_SECRET, PORT=3001
  • Start backend: node src/index.js (port 3001)
  • Start frontend: npm run dev (port 5173)
  • Register an account and start tracking!

Testing Strategy

  • Backend: Jest + Supertest for unit and integration tests; fast-check for property-based correctness tests
  • Frontend: Vitest + React Testing Library; @fast-check/vitest for chart data and filter logic properties
  • Run backend tests: cd server && npm test
  • Run frontend tests: cd client && npm test
