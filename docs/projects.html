Project Description

The Budget Tracker is a full-stack web application that enables authenticated users to record, categorise, and visualise personal income and expense transactions. The system follows an MVC architecture with a RESTful JSON API backend and a single-page application (SPA) frontend.

Core goals include secure per-user data isolation enforced at every API layer, a responsive UI that works from 320px to 2560px viewports, and rich data visualisations (pie, bar, and line charts) that update reactively as the user adjusts date filters.

Architecture

The application is split into two independently deployable packages inside a monorepo: a Node.js / Express REST API backend and a React (Vite) SPA frontend.

Monorepo Structure
  • server/ — Express API: config, middleware, models, routes, services, utils
  • client/ — React SPA: api, components, hooks, pages, utils

Request Flow
  • Browser → React SPA → Express API (HTTP + JWT header)
  • JWT Auth Middleware verifies token → attaches userId or returns 401
  • Service Layer executes Sequelize query against PostgreSQL
  • JSON response → React re-renders charts and data

Key Features

  • User registration & login with JWT authentication (24-hour tokens, bcrypt password hashing)
  • Create, read, update, and delete budget entries with amount, type, category, date, and description
  • Custom and default category management per user
  • Dashboard with income/expense summary cards and top-5 expense categories
  • Interactive pie chart (expenses by category), bar chart (monthly income vs expenses), and line chart (cumulative balance)
  • Date-range filtering that drives all dashboard queries reactively
  • Fully responsive layout with hamburger navigation below 768px
  • Strict per-user data isolation — users can never access each other's data

Data Models

Three core Sequelize models backed by PostgreSQL:

// User — stores credentials
{ id, email (unique), password_hash, created_at, updated_at }

// Category — default (user_id = NULL) or user-owned
{ id, name, user_id (FK), is_default, created_at }
// Unique constraint: (name, user_id)

// BudgetEntry — core transaction record
{ id, user_id (FK), category_id (FK), amount (DECIMAL 12,2),
  type (ENUM: income|expense), entry_date, description, created_at, updated_at }

Sample Code — JWT Auth Middleware

// server/src/middleware/auth.js
const jwt = require('jsonwebtoken');

module.exports = (req, res, next) => {
  const authHeader = req.headers['authorization'];
  const token = authHeader && authHeader.split(' ')[1]; // Bearer <token>

  if (!token) {
    return res.status(401).json({
      error: { code: 'MISSING_TOKEN', message: 'Authentication required.' }
    });
  }

  try {
    const payload = jwt.verify(token, process.env.JWT_SECRET);
    req.userId = payload.userId;
    next();
  } catch (err) {
    return res.status(401).json({
      error: { code: 'INVALID_TOKEN', message: 'Token is invalid or expired.' }
    });
  }
};

Sample Code — Budget Entry Filter Query

// server/src/services/budgetService.js (getEntries)
const { Op } = require('sequelize');

async function getEntries(userId, { startDate, endDate, categoryId, type }) {
  const where = { user_id: userId };

  if (startDate) where.entry_date = { [Op.gte]: startDate };
  if (endDate)   where.entry_date = { ...where.entry_date, [Op.lte]: endDate };
  if (categoryId) where.category_id = categoryId;
  if (type)       where.type = type;

  return BudgetEntry.findAll({
    where,
    order: [['entry_date', 'DESC']],
    include: [{ model: Category, attributes: ['name'] }]
  });
}
